# 歐陸原創 51 部:三語標題查證

## 規則(依 i18n_maps 既有策展政策 + 使用者 2026-09-01 指示)
- `show_titles`(简)/ `show_titles_tw`(繁)只收**中文圈確實通行的譯名**;
  gen_variants 會把它當 `cn_annot` **加註**在原題旁,不取代原題。
- **查不到對應中文劇名的,絕不硬翻**——列進「不譯清單」交代原因。
- 繁簡要分別查(台灣用語 vs 中國用語不同,不是換字而已)。
- 英文標題走 `title_en`(gen_variants 的 `enTitle()`);只填**官方英文名**,
  沒有官方英文名的維持原文題名。

## 判定分級
- **A 官方**:該製作/劇團自己發布過中文名,或中文圈有正式引進演出
- **B 通行**:原著小說/電影在台灣或中國有通行中譯,且音樂劇沿用同名
- **C 不譯**:中文圈查無對應名稱 → 不填,列 note
